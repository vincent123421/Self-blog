## 模块化AI驱动个人数字空间 R1 阶段项目计划书

---

### 1. 项目概述

*   **项目名称：** 模块化AI驱动个人主页原型
*   **项目愿景：** 旨在构建一个高度个性化、模块化、可扩展的个人数字空间。在 R1 阶段，我们希望通过开发一个**“超级个人主页/生活仪表盘”**作为载体，验证核心的模块化架构、运行时管理及配置文件驱动能力，为未来宏大的AI赋能与开放生态奠定基础。
*   **阶段目标 (R1)：**
    1.  成功构建一个**可部署的 Web 版“个人仪表盘”MVP**。
    2.  实现仪表盘内**功能模块的加载、渲染与简单配置持久化**，并完全由外部配置文件驱动。
    3.  建立一套**简易的“模块契约”和“模块管理器”**，初步实践模块化开发思想。
    4.  培养团队在**前端架构、模块化开发和工程实践**方面的能力。

---

### 2. 项目背景与需求分析 

**2.1 项目背景：**
当前数字世界中，用户面临信息过载、工具碎片化、个性化需求难以满足等痛点。现有工具（如笔记软件、仪表盘扩展）虽有部分模块化或定制功能，但普遍缺乏真正的开放性、AI 驱动的功能生成能力，且功能扩展受限于内置组件。本项目的R1阶段旨在验证通过模块化架构解决部分痛点，为更宏大的愿景铺路。

**2.2 需求分析 (R1 阶段用户需求)：**
*   **核心用户：** 对个性化数字工作/生活空间有需求的用户。
*   **痛点：**
    *   想要一个能集中展示个人信息、兴趣、项目、常用工具的页面，但现有工具太死板。
    *   需要一个灵活的界面，可以自由增减和调整不同的信息卡片或功能。
    *   希望可以灵活调用不同软件的api，形成一个软件中枢。
    *   希望自己的页面或仪表盘能保存设置，下次打开不变。
*   **期望：**
    *   能定制标题、文字内容、链接等。
    *   能展示时钟、简单的待办事项。
    *   页面美观，可对外分享。

### 3. R1 阶段范围与功能

**3.1 核心功能 (MVP)：**

*   **基础容器：**
    *   基于 React + Vite 的前端应用框架。
    *   具备一个灵活的网格布局系统（ `react-grid-layout`），用于模块的定位与渲染。
    *   支持用户通过拖拽调整模块的位置和大小。
*   **模块管理：**
    *   **模块加载：** 能够根据配置文件动态加载和实例化预定义的内部模块。
    *   **模块契约：** 明确每个模块的元数据定义（`module.json`）和 JS 接口（`render`, `unmount`, `init` 等）。
    *   **模块管理器 (Manager)：** 负责维护模块实例、传递核心 API、协调模块生命周期。
*   **核心模块 (至少实现以下模块)：**
    *   **`WelcomeModule`：** 可配置标题、文本和头像。
    *   **`TextCardModule`：** 显示自定义富文本内容。
    *   **`LinkListModule`：** 显示可配置的链接列表（标题、URL、图标）。
    *   **`ClockModule`：** 显示当前时间。
    *   **`TodoModule` (简易版)：** 一个基于 `localStorage` 的简易待办事项列表（添加、标记完成、删除）。
*   **配置与持久化：**
    *   用户对仪表盘的布局和模块的配置（如文本卡片内容、链接列表数据）可保存到 `localStorage`。
    *   应用启动时自动从 `localStorage` 加载配置，渲染仪表盘。
    *   提供一个基础的“添加/删除模块”操作界面。

### 6. 核心技术架构设计

**6.1 模块系统核心设计（R1阶段简化版）：**
*   **模块生命周期：** `init()` → `render()` → `unmount()`
*   **模块契约接口：**
    ```javascript
    {
      id: string,
      name: string,
      version: string,
      component: ReactComponent,
      defaultConfig: object,
      configSchema: object // 用于配置验证
    }
    ```
*   **模块独立性：** 每个模块完全独立，通过props接收配置
*   **全局状态：** 仅处理主题切换等基础全局状态（使用Zustand）

**6.2 数据持久化方案：**
*   **R1阶段：** localStorage + JSON Schema验证
*   **R2阶段：** IndexedDB + 云端同步
*   **数据结构：**
    ```javascript
    {
      layout: { modules: [], grid: {} },
      moduleConfigs: { [moduleId]: config },
      globalSettings: { theme, fonts, etc }
    }
    ```

**6.3 性能优化策略：**
*   **模块懒加载：** 使用 `React.lazy()` 和动态 `import()`
*   **代码分割：** 按模块分割打包
*   **图片优化：** 自动压缩、WebP格式转换、CDN集成
*   **缓存策略：** 模块配置缓存、API响应缓存

### 7. 安全性考虑

**7.1 自定义代码模块安全：**
*   **沙箱环境：** 使用 `iframe` + `postMessage` 隔离执行
*   **CSP策略：** 严格的内容安全策略
*   **代码审查：** 静态代码分析和恶意代码检测
*   **权限控制：** 模块API访问权限限制

**7.2 数据安全：**
*   **输入验证：** 所有用户输入的严格验证和清理
*   **XSS防护：** 富文本内容的安全渲染
*   **文件上传安全：** 文件类型检查、大小限制、病毒扫描

## 模块（Module）的定义

“模块”是构成用户页面的基本、独立、可复用的**功能单元或内容展示单元**。

可以将其理解为：

*   **乐高积木：** 每个模块都是一块积木，用户可以自由选择、组合、排列这些积木来构建自己的页面。
*   **应用程序中的插件：** 模块像是一个小型、专门的插件，负责实现特定的功能或展示特定类型的内容。
*   **网页组件：** 在前端开发中，模块类似于一个独立的UI组件，拥有自己的数据、逻辑和视图。

**核心特性：**

1.  **独立性：** 每个模块都应是独立的，可以单独存在和运行，不强烈依赖其他模块。
2.  **可配置性：** 模块提供配置项（如内容、样式、行为），允许用户进行自定义。
3.  **可复用性：** 相同的模块可以在页面中被多次使用（例如，多个图片画廊模块）。
4.  **可插拔性：** 用户可以随时添加、删除、拖拽和重新排序模块。
5.  **功能封装：** 模块封装了特定的功能或内容类型，对外提供统一的接口。
6.  **可扩展性（核心亮点）：** 平台支持开发者和用户（通过AI）创建新的模块，不断丰富模块库。

---

## 模块的功能（Functionality of a Module）

一个模块通常包含以下功能层：

1.  **数据输入与管理：**
    *   **收集信息：** 提供界面让用户输入数据（如文本、图片、视频链接、项目描述等）。
    *   **数据存储：** 将用户输入的数据与该模块实例关联并存储。
    *   **数据处理：** 对输入的数据进行初步处理（如图片压缩、文本格式化）。

2.  **内容展示：**
    *   **视觉呈现：** 以用户友好的方式在页面上渲染数据（文本、图片、图表、表格、媒体播放器等）。
    *   **响应式设计：** 模块内容应能适应不同设备屏幕尺寸。

3.  **交互行为：**
    *   **用户交互：** 处理用户在模块上的操作（如点击按钮、提交表单、滑动轮播图）。
    *   **动态效果：** 提供动画、过渡效果等，提升用户体验。
    *   **外部通信：** 如果需要，模块可以与外部服务进行数据交互（如获取天气数据、发送邮件）。

4.  **样式与布局控制：**
    *   **样式配置：** 允许用户调整模块的颜色、字体、背景、边距、边框等视觉属性。
    *   **内部布局：** 控制模块内部元素的排列方式（如图片网格、列表、左右布局）。
    *   **与整体布局集成：** 模块应能很好地融入页面的整体布局系统（如拖拽到某个列或区域）。

5.  **（高级）逻辑处理：**
    *   **业务逻辑：** 实现模块特有的业务逻辑（如计数器、动态数据加载、条件显示）。
    *   **事件处理：** 触发或响应平台级的事件。

## 模块的可能例子 (Examples of Modules)

为了更好地理解，我们将其分为几类：

### 1. **基础信息与介绍类模块**

*   **个人简介模块 (Bio Module):**
    *   **功能：** 显示用户的头像、姓名、职位/Slogan、简短介绍。
    *   **配置：** 头像上传、文字内容编辑（富文本）、字体样式、背景色、对齐方式。
*   **封面英雄区模块 (Hero Section Module):**
    *   **功能：** 页面顶部的视觉焦点，通常包含大图/视频背景、标题、副标题和行动号召按钮。
    *   **配置：** 背景图片/视频上传、标题/副标题文字、按钮文本与链接、叠加层颜色与透明度。
*   **联系方式模块 (Contact Info Module):**
    *   **功能：** 显示邮箱、电话、社交媒体链接等联系信息。
    *   **配置：** 各类联系方式输入框、图标选择、布局（列表/网格）、显示/隐藏特定信息。

### 2. **作品与内容展示类模块**

*   **图片画廊模块 (Image Gallery Module):**
    *   **功能：** 展示一组图片，支持点击放大、轮播、网格布局。
    *   **配置：** 多图上传、布局选择（网格、瀑布流、轮播）、图片标题/描述、点击行为（放大、跳转链接）。
*   **视频播放器模块 (Video Player Module):**
    *   **功能：** 嵌入YouTube、Bilibili、Vimeo等外部视频，或上传本地视频。
    *   **配置：** 视频URL输入、自动播放、循环播放、控制条显示。
*   **项目案例模块 (Project Showcase Module):**
    *   **功能：** 展示单个或多个项目，包含项目标题、描述、图片/视频、链接。
    *   **配置：** 项目名称、图片/视频、详细描述（富文本）、项目链接、发布日期、标签。
*   **文章/博客列表模块 (Blog Post List Module):**
    *   **功能：** 显示用户的文章列表，可链接到文章详情页（如果是平台内置博客系统）或外部链接。
    *   **配置：** 文章标题、摘要、缩略图、发布日期、排序方式（最新、最热）、显示数量。
*   **下载文件模块 (File Download Module):**
    *   **功能：** 提供可下载的文件（如简历PDF、作品集ZIP）。
    *   **配置：** 文件上传、显示文本、下载按钮样式。

### 3. **专业技能与经历类模块**

*   **技能条/进度模块 (Skills Bar/Progress Module):**
    *   **功能：** 以进度条、圆环图或标签形式展示各项技能及熟练度。
    *   **配置：** 技能名称、熟练度百分比/星级、颜色。
*   **教育与工作经历模块 (Experience Timeline Module):**
    *   **功能：** 以时间轴形式展示教育背景和工作经历。
    *   **配置：** 公司/学校名称、职位/专业、起止日期、职责描述。
*   **证书/奖项模块 (Certificates/Awards Module):**
    *   **功能：** 展示获得的证书、奖项图片或文字描述。
    *   **配置：** 证书图片上传、名称、颁发机构、日期。

### 4. **互动与社交类模块**

*   **社交媒体链接模块 (Social Media Links Module):**
    *   **功能：** 一排社交媒体图标，点击可跳转到对应平台。
    *   **配置：** 选择需要显示的社交平台（Facebook, Twitter, Instagram, LinkedIn等）、输入个人主页链接、图标样式。
*   **表单模块 (Form Module):**
    *   **功能：** 允许访客提交信息（如联系表单、订阅表单）。
    *   **配置：** 表单字段（姓名、邮箱、消息），提交按钮文本，提交后消息，数据接收方式（例如，发送到指定邮箱）。
*   **留言板/评论模块 (Guestbook/Comments Module):**
    *   **功能：** 允许访客留下公开留言或评论。
    *   **配置：** 开启/关闭审核、显示最新评论数量、留言字段。

### 5. **程序员专业模块**

*   **GitHub统计卡片模块 (GitHub Stats Module):**
    *   **功能：** 展示GitHub个人统计信息，如总star数、commit数、PR数、语言分布等。
    *   **配置：** GitHub用户名、显示项目选择、卡片样式、颜色主题。
*   **LeetCode进度模块 (LeetCode Progress Module):**
    *   **功能：** 展示LeetCode刷题进度、难度分布、最近提交记录。
    *   **配置：** LeetCode用户名、显示统计类型、进度条样式。
*   **技术博客聚合模块 (Tech Blog Aggregator Module):**
    *   **功能：** 聚合展示来自掘金、CSDN、知乎等平台的技术文章。
    *   **配置：** 平台选择、用户ID、文章数量、排序方式。
*   **代码提交热力图模块 (Commit Heatmap Module):**
    *   **功能：** 类似GitHub的贡献热力图，展示代码提交活跃度。
    *   **配置：** 数据源（GitHub/GitLab）、时间范围、颜色方案。
*   **技术栈雷达图模块 (Tech Stack Radar Module):**
    *   **功能：** 以雷达图形式展示各技术领域的熟练程度。
    *   **配置：** 技术分类、熟练度评分、图表样式、标签显示。

### 6. **高级/特殊功能模块**

*   **定制HTML/CSS模块 (Custom HTML/CSS Module):**
    *   **功能：** 允许高级用户直接插入HTML和CSS代码，实现高度定制。
    *   **配置：** 代码编辑器。 (需要严格的安全沙箱)
*   **外部小部件嵌入模块 (External Widget Embed Module):**
    *   **功能：** 嵌入来自第三方服务的小部件，如日程预约（Calendly）、在线客服（Intercom）、地图（Google Maps）。
    *   **配置：** 嵌入代码片段。
*   **动态数据图表模块 (Dynamic Chart Module):**
    *   **功能：** 根据用户提供的数据或外部API数据，生成可交互图表（如柱状图、折线图）。
    *   **配置：** 数据输入（手动输入、CSV上传、API接口）、图表类型、颜色、标题。
*   **倒计时模块 (Countdown Timer Module):**
    *   **功能：** 显示一个到特定日期的倒计时。
    *   **配置：** 目标日期和时间、显示文本、样式。
*   **在线代码运行器模块 (Code Runner Module):**
    *   **功能：** 支持在线编写和运行代码片段（JavaScript、Python等）。
    *   **配置：** 支持语言选择、代码模板、执行环境配置。

    *   **数据输入：** 代码文本输入（可能带语法高亮插件）、描述文本、外部嵌入代码。
    *   **内容展示：** 渲染带有语法高亮的代码块，或嵌入的外部内容。
    *   **高级功能：** 代码片段模块可能支持版本控制、diff查看，甚至运行小段代码（沙箱环境）。

#### 7. **联系方式模块 (Contact Info Module)**

*   **目的：** 提供清晰的联系方式。
*   **如何使用：**
    *   **添加：** 添加“联系方式模块”到页面底部或侧边栏。
    *   **配置：**
        *   **Email：** 你的邮箱地址。
        *   **LinkedIn：** 你的LinkedIn个人主页链接。
        *   **GitHub：** 你的GitHub主页链接（虽然有日历模块，但这里是直接的链接入口）。
        *   **Twitter/知乎等：** 其他你常用的社交或技术社区链接。
        *   **位置/城市：** (可选) 如 "上海" 或 "远程工作"。
        *   **样式：** 图标大小、排列方式、颜色。
*   **功能实现：**
    *   **数据输入：** 各类联系信息的文本输入框和链接输入框。
    *   **内容展示：** 显示图标和链接。
    *   **交互：** 点击图标跳转到对应平台。

#### 8. **页脚模块 (Footer Module)**

*   **目的：** 版权信息、快速链接，保持专业感。
*   **如何使用：**
    *   **添加：** 添加“页脚模块”到页面最底部。
    *   **配置：**
        *   **版权信息：** "© 2023 张三. All rights reserved."
        *   **快速链接：** 隐私政策、服务条款（如果需要）。
        *   **样式：** 背景色、文字颜色。
*   **功能实现：**
    *   **数据输入：** 文本输入、链接输入。
    *   **内容展示：** 显示文本和链接。

### 第三步：拖拽排布与全局样式调整

现在，你已经添加了所有需要的模块。你可以在编辑界面：

*   **拖拽模块：** 根据逻辑和视觉流畅性，调整模块的上下顺序，甚至将其放入不同的列中（如果布局模板支持）。
*   **调整尺寸：** 调整模块的宽度、高度（如“封面英雄区”可以设置高度）。
*   **全局样式：**
    *   **配色方案：** 选择一个主色调和辅助色调，如深蓝色和亮黄色，体现科技感。
    *   **字体：** 选择适合代码展示的等宽字体和适合阅读的无衬线字体。
    *   **背景：** 选择整个页面的背景颜色或纹理。

### 总结

通过这种模块化的方式，一个程序员可以：

*   **高效构建：** 无需编写任何代码，通过简单的拖拽和配置即可完成专业页面。
*   **高度定制：** 每个模块的内容和样式都可以个性化，展现独特的代码风格和品味。
*   **突出重点：** 根据求职、合作等不同目的，调整模块的展示顺序和突出程度。
*   **保持更新：** 有了新项目、新技能或新贡献，只需编辑相应的模块即可，无需重新搭建页面。
